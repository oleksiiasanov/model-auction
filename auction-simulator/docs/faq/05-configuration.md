## Як очистити старі дані симуляції?

**🏷️ Теги:** `configuration`, `cleanup`, `maintenance`

**❓ Питання:**
Як видалити старі cache файли та outputs щоб звільнити місце?

**💡 Коротка відповідь:**
Використовуйте `--clean` flag перед запуском симуляції.

**📚 Детальна відповідь:**

### Що видаляється?

При використанні `--clean` flag:
- **Cache**: Видаляються всі файли з `data/cache/`
- **Outputs**: Видаляються старі файли, зберігаються останні 5 запусків

### Приклад використання:

```bash
python -m auction_simulator.cli simulate \
  --country 13 \
  --categories 1361 \
  --time-from 2026-02-01 \
  --time-to 2026-02-01 \
  --clean
```

### Вивід:

```
Cleaning up before simulation...
  Cache: 12 files removed (45.3 MB freed)
  Outputs: 18 files removed, 5 most recent kept (23.1 MB freed)
Starting simulation...
```

### Що таке "один запуск"?

Один запуск = 3 файли з однаковим timestamp:
- `ad_comparison_20260201_120000.csv`
- `seller_comparison_20260201_120000.csv`
- `summary_statistics_20260201_120000.txt`

### Налаштування кількості збережених запусків:

За замовчуванням зберігається 5 останніх запусків. Змінити можна у `config/local.yaml`:

```yaml
cleanup:
  keep_last_runs: 3  # Зберігати тільки 3 останні запуски
```

### Коли використовувати?

- ✅ Перед важливим запуском (чистий slate)
- ✅ Коли диск заповнюється
- ✅ Після зміни параметрів симуляції (щоб не плутати з старими results)
- ✅ Регулярно (наприклад, раз на тиждень)

### Що станеться зі старими файлами?

Файли **видаляються назавжди** (не переміщуються в корзину). Переконайтесь що важливі результати збережені в іншому місці.

### Поєднання з --no-cache:

```bash
# Видалити cache + не створювати новий
python -m auction_simulator.cli simulate \
  --clean \
  --no-cache \
  ...
```

- `--clean`: Видаляє старі файли перед запуском
- `--no-cache`: Відключає створення нового кешу під час екстракції даних
