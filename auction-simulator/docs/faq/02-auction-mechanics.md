## Як розраховується effective_bid?

**🏷️ Теги:** `auction`, `bidding`, `formula`

**❓ Питання:**
Як розраховується effective_bid для кожного оголошення?

**💡 Коротка відповідь:**
```python
effective_bid = min_bid + (N - 1 - rank_index) × bid_step
```

**📚 Детальна відповідь:**

### Покрокова процедура:

**Крок 1: Розрахунок pressure**
```python
for ad in ads:
    ad.pressure = ad.remaining_budget / max(time_left, 0.001)
```

**Крок 2: Сортування та присвоєння рангів**
```python
ads_sorted = sorted(ads, key=lambda ad: ad.pressure, reverse=True)
for rank_index, ad in enumerate(ads_sorted):
    ad.rank = rank_index  # 0, 1, 2, ..., N-1
```

**Крок 3: Підрахунок N**
```python
N = len([ad for ad in ads if ad.remaining_budget > 0])
```

**Крок 4: Розрахунок effective_bid**
```python
for ad in ads:
    ad.effective_bid = min_bid + (N - 1 - ad.rank) * bid_step
```

### Конкретний приклад:

**Параметри:**
- `min_bid` = 0.0702 коп.
- `bid_step` = 0.001 коп.
- `N` = 81 оголошень

**Розрахунок:**

| Ad | Pressure | Rank | Формула | Effective Bid |
|----|----------|------|---------|---------------|
| A | 500.0 | 0 | 0.0702 + (81-1-0)×0.001 | 0.1502 коп. |
| B | 350.0 | 1 | 0.0702 + (81-1-1)×0.001 | 0.1492 коп. |
| C | 200.0 | 40 | 0.0702 + (81-1-40)×0.001 | 0.1102 коп. |
| ... | ... | ... | ... | ... |
| Z | 10.0 | 80 | 0.0702 + (81-1-80)×0.001 | 0.0702 коп. |

**💻 Код:**

```python
# Локація: auction_engine.py:180-185
def calculate_effective_bid(
    self,
    rank_index: int,
    ads_with_budget_count: int
) -> float:
    N = max(ads_with_budget_count, 1)  # Мінімум 1
    bonus = (N - 1 - rank_index) * self.bid_step
    effective_bid = self.min_bid + bonus
    return effective_bid
```

## N=300 чи N=40?

**🏷️ Теги:** `auction`, `N`, `batch_size`, `competition`

**❓ Питання:**
Якщо у нас 300 активних платних кампаній, а батч відбирає 40 оголошень, максимальна ставка вираховується серед 300 оголошень чи серед 40?

**💡 Коротка відповідь:**
**N = 300** (всі платні оголошення), **НЕ 40** (розмір батчу)

**📚 Детальна відповідь:**

### Процес аукціону:

```
1. ВСІ 300 оголошень обчислюють effective_bid з N=300
   ├─ Ранг 0: bid = min_bid + 299×bid_step (найвища)
   ├─ Ранг 149: bid = min_bid + 150×bid_step (середина)
   └─ Ранг 299: bid = min_bid + 0×bid_step (найнижча)

2. Сортування 300 оголошень за effective_bid (↓)

3. Топ-40 виграють
   ├─ Переможець #1 (ранг 0): платить min_bid + 299×bid_step
   ├─ Переможець #40 (ранг 39): платить min_bid + 260×bid_step
   └─ Оголошення #41 (ранг 40): НЕ виграє

4. Кожен платить свою ставку (first-price auction)
```

### Порівняння: N=300 vs N=40

**✅ ПРАВИЛЬНО (N=300):**

```
300 оголошень → обчислюють ставки з N=300 → топ-40 виграють

Ранг   | Effective Bid (приклад)     | Статус
-------|-----------------------------|-----------
0      | 0.07 + 299×0.001 = 0.369   | ✅ ВИГРАЄ #1
1      | 0.07 + 298×0.001 = 0.368   | ✅ ВИГРАЄ #2
...    | ...                         | ...
39     | 0.07 + 260×0.001 = 0.330   | ✅ ВИГРАЄ #40
40     | 0.07 + 259×0.001 = 0.329   | ❌ НЕ ВИГРАЄ
...    | ...                         | ...
299    | 0.07 + 0×0.001 = 0.070     | ❌ НЕ ВИГРАЄ
```

**❌ НЕПРАВИЛЬНО (якби N=40):**

```
300 оголошень → обчислюють ставки з N=40 → топ-40 виграють

Ранг | Effective Bid          | Проблема
-----|------------------------|---------------------------
0    | 0.07 + 39×0.001 = 0.109 | Занадто низька ставка!
39   | 0.07 + 0×0.001 = 0.070  | = min_bid (немає конкуренції)
```

**Проблема:** Ставки не відображають реальну конкуренцію між 300 оголошеннями!

### Чому так важливо?

**Приклад (N=81, batch_size=40):**

| Параметр | Значення | Пояснення |
|----------|----------|-----------|
| **Всього ads з бюджетом** | 81 | N = 81 |
| **Слотів у батчі** | 40 | batch_size = 40 |
| **Max bid (ранг 0)** | 0.1502 коп. | 0.0702 + 80×0.001 |
| **40-й переможець (ранг 39)** | 0.1112 коп. | 0.0702 + 41×0.001 |
| **41-й (НЕ виграє, ранг 40)** | 0.1102 коп. | 0.0702 + 40×0.001 |
| **Останній (ранг 80)** | 0.0702 коп. | = min_bid |

**Якби використовували N=40:**
- Max bid = 0.0702 + 39×0.001 = 0.1092 коп.
- Це **в 1.4 рази менше** реальної конкуренції!

### Висновок:

✅ **N = всі оголошення з бюджетом** (відображає реальну конкуренцію)
❌ **N ≠ batch_size** (це лише кількість слотів)

**💻 Код:**

```python
# Локація: auction_engine.py:155-160
ads_with_budget = [ad for ad in eligible if ad.remaining_budget > 0]
N = len(ads_with_budget)  # НЕ batch_size!

for rank_index, ad in enumerate(ads_ranked):
    effective_bid = self.min_bid + (N - 1 - rank_index) * self.bid_step
```

## Чому формула (N-1-rank)?

**🏷️ Теги:** `formula`, `ranking`, `auction`

**❓ Питання:**
Чому формула effective_bid = min_bid + (N-1-rank)×bid_step, а не просто min_bid + rank×bid_step?

**💡 Коротка відповідь:**
Щоб **інвертувати** позицію: найвища pressure → найвища ставка

**📚 Детальна відповідь:**

### Проблема з формулою rank×bid_step:

Якби використовували `min_bid + rank × bid_step`:

| Pressure | Rank | Ставка | Проблема |
|----------|------|--------|----------|
| 500 (найвища) | 0 | min_bid + 0 = 0.0702 | ❌ Найнижча ставка! |
| 10 (найнижча) | 80 | min_bid + 80×0.001 = 0.1502 | ❌ Найвища ставка! |

**Це навпаки!** Найвища pressure платила б найменше.

### Рішення: (N-1-rank)

Формула `(N - 1 - rank)` інвертує позицію:

| Pressure | Rank | (N-1-rank) | Ставка | Результат |
|----------|------|------------|--------|-----------|
| 500 (найвища) | 0 | (81-1-0) = 80 | min_bid + 80×step | ✅ Найвища ставка |
| 350 | 1 | (81-1-1) = 79 | min_bid + 79×step | ✅ Друга за величиною |
| ... | ... | ... | ... | ... |
| 10 (найнижча) | 80 | (81-1-80) = 0 | min_bid + 0 = min_bid | ✅ Найнижча ставка |

### Математика:

```python
# Якщо N = 81, rank ∈ [0, 80]:
bonus = (N - 1 - rank) = (81 - 1 - rank) = (80 - rank)

# Діапазон:
rank = 0  → bonus = 80 (максимум)
rank = 40 → bonus = 40 (середина)
rank = 80 → bonus = 0  (мінімум)
```

**Візуалізація:**

```
Pressure (↑)     Rank      Bonus        Effective Bid (↑)
     ↑            0    →   80×step  →        ↑
     |            1    →   79×step  →        |
     |            2    →   78×step  →        |
     |           ...   →    ...     →        |
     |           40    →   40×step  →        |
     |           ...   →    ...     →        |
     |           79    →   1×step   →        |
     ↓           80    →   0×step   →        ↓
```

**💻 Код:**

```python
# Локація: auction_engine.py:182
bonus = (N - 1 - rank_index) * self.bid_step
effective_bid = self.min_bid + bonus

# Альтернативний запис:
effective_bid = self.min_bid + (N - 1 - rank_index) * self.bid_step
```
